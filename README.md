# 🦀 shard

> **yt-dlp TUI downloader built with Rust, Ratatui, and Kitty Graphics Protocol.**

YouTube 等のストリーミングサイトから、動画や音声をキーボード操作でダウンロード・整理するための TUI ツールです。

---

## 主な機能

1. **メタデータ確認後のダウンロード**:
   - URL 入力後、タイトル・再生時間・ストリーム構成・サムネイルを画面に表示します。
   - 内容を確認した上で、`Enter` キーを押してダウンロードを開始します。
2. **ダウンロードモードの切り替え**:
   - **通常ダウンロード (`Enter`)**:
     - 設定（動画の解像度上限、音声フォーマット等）に応じたストリームを自動選択してダウンロードします。
   - **特定ストリームの個別選択 (`F`)**:
     - `-F` フォーマット一覧モーダルから、任意の動画・音声ストリームを指定してダウンロードできます。
3. **ディレクトリ移動と新規フォルダ作成**:
   - `d` キーでディレクトリブラウザを開き、サブフォルダの選択や新規フォルダ作成（`n` / `+`）が行えます。
   - yazi ライクなキー操作（`h` で親、`l` で子フォルダ）に対応しています。
4. **デフォルト保存先 (設定で変更可能)**:
   - 音声モード: `~/Music`（または設定したパス）
   - 動画モード: `~/Videos`
   - ローカル: `~/Downloads`
5. **アートワーク / サムネイルの個別ダウンロード (`i` キー)**:
   - 音声・動画ファイルとは独立して、画像（ジャケットやサムネイル）を個別に選択・保存できます。
6. **アルバム / プレイリスト対応**:
   - アルバムやプレイリストの URL を入力した場合、アルバム名、曲数、トラック一覧を左右2列で一覧表示します。
7. **MusicBrainz Picard 連携 (`p` キー)**:
   - `p` キーで Picard を起動し、ダウンロード先フォルダを直接開きます。
8. **クリップボード連携・通知**:
   - `v` キーでクリップボードの URL を取得します（起動時の自動取得は行いません）。
   - 処理完了時はデスクトップ通知を送信します。

## ⌨️ キーバインド一覧

### メイン画面
| キー | アクション |
| :--- | :--- |
| `v` | クリップボードから URL を貼り付け（メディア情報を取得開始） |
| `u` / `/` | URL を手動入力するモードへ切り替え |
| `Enter` | **ダウンロード開始**（メディア情報確認後に明示的に実行） |
| `Tab` | モード切替 (`Video` → `Audio` → `ThumbnailOnly`) |
| `r` | 動画の解像度上限切替 (`Unlimited` → `1080p` → `720p` → ...) |
| `a` | 音声フォーマット切替 (`MP3` → `FLAC` → `OPUS` → `M4A`) |
| `i` | **アートワーク / サムネイル選択モーダルを開く** |
| `F` / `f` | **`-F` ストリーム選択モーダルを開く**（特定ファイルだけ選択） |
| `d` | **保存先ディレクトリ選択 / 新規フォルダ作成モーダルを開く** |
| `p` / `P` | **MusicBrainz Picard を起動**（ダウンロード先フォルダを開く） |
| `q` | 終了 |

### 保存先ディレクトリブラウザ (`d` キー)
| キー | アクション |
| :--- | :--- |
| `j` / `Down` | 下へ移動 |
| `k` / `Up` | 上へ移動 |
| `h` / `Left` | **親ディレクトリへ戻る** (yaziライク) |
| `l` / `Right` / `Enter` | **選択中のフォルダを開く**（サブディレクトリへ入る） (yaziライク) |
| `Space` | **現在開いているフォルダを保存先として確定** |
| `n` / `+` | **新規フォルダを作成 (mkdir)**（名前を入力して Enter） |
| `1` 〜 `9` | 登録ルートディレクトリを即座に切り替え |
| `Esc` / `q` | 閉じる |

### アートワーク / サムネイル選択モーダル (`i` キー)
| キー | アクション |
| :--- | :--- |
| `j` / `Down`, `k` / `Up` | 画像候補を選択 |
| `Enter` | 選択中の画像をダウンロード保存（`cover.jpg` 等） |
| `a` | 最高画質（おまかせ）を自動保存 |
| `Esc` / `i` / `q` | 閉じる |

### `-F` フォーマット選択モーダル (`F` キー)
| キー | アクション |
| :--- | :--- |
| `j` / `Down`, `k` / `Up` | 下 / 上へ移動 |
| `Space` | 映像ストリーム（Video）の選択 / 解除 |
| `a` | 音声ストリーム（Audio）の選択 / 解除 |
| `c` | カスタムフォーマット選択のクリア（おまかせ自動選択に戻す） |
| `Enter` / `Esc` / `q` | 確定してモーダルを閉じる |

## ⚙️ 設定ファイル (`~/.config/shard/config.toml`)

初回起動時に自動生成されます：

```toml
[general]
default_mode = "video"
max_resolution = "unlimited"
auto_paste_clipboard = false
notify_on_complete = true

[audio]
format = "mp3"
quality = "0"
embed_thumbnail = false
add_metadata = true

# 登録ルートディレクトリ
[[bookmarks]]
id = 1
name = "Music"
path = "/path/to/Music"
category = "audio"

[[bookmarks]]
id = 2
name = "Videos"
path = "/path/to/Videos"
category = "video"

[[bookmarks]]
id = 3
name = "Downloads"
path = "/path/to/Downloads"
category = "any"
```

## 🚀 起動方法

```bash
git clone https://github.com/LilacAoi/shard.git
cd shard

# 1. ビルド＆実行
cargo run

# または Nix による直接実行
nix run .

# または nix build
nix build
./result/bin/shard
```
