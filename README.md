# 🦀 shard

> **A fast, ergonomic yt-dlp TUI downloader built with Rust, Ratatui, and Kitty Graphics Protocol.**

YouTube や各種ストリーミングサイトから、動画や音声をキーボード操作のみで爆速かつ快適にダウンロード・整理できる専用 TUI ツールです。

---

## ✨ 主な特徴と改善点

1. **🛡️ 安全で確実な情報確認フロー (勝手にダウンロードしない)**:
   - URL を貼り付けたり入力しても、**いきなりダウンロードが始まることはありません**。
   - まずバックグラウンドで `yt-dlp` がメディア情報とサムネイル画像を高速取得し、TUI 上にタイトル・チャンネル・時間・ストリーム構成・画像を美しく展開します。
   - 内容を目視確認した上で、**明示的な指示（`Enter` キー等）があって初めてダウンロードが開始されます**。
2. **🌟 「おまかせダウンロード」 vs 「特定のファイル/ストリームだけダウンロード」**:
   - **おまかせダウンロード (`Enter`)**:
     - 現在のモード設定（動画: 解像度上限フィルタ、音声: 最高音質MP3/FLAC等）に基づき、最高品質のストリームを全自動選択してダウンロード。
   - **特定のファイル/ストリームだけダウンロード (`F`)**:
     - `-F` フォーマット一覧モーダルから、特定の動画IDや音声ID、あるいは動画のみ（音声なし）、音声のみを選択してダウンロード可能。
3. **📂 階層型ディレクトリブラウザ ＆ 新規フォルダ作成 (`mkdir`)**:
   - `d` キーでディレクトリブラウザを展開。
   - 登録ルートディレクトリ（外付けHDDの音楽・動画、ローカルDownloads等）から、実際のサブフォルダを階層移動して選択可能。
   - **新規フォルダ作成 (`n` キー / `+` キー)**: その場で新しいアーティスト名やカテゴリのフォルダを即座に作成し、そのままダウンロード先に設定できます。
4. **💾 デフォルトダウンロード先 (設定で自由に変更可能)**:
   - 🎵 音声モード時: `~/Music`（または外付けHDDなどの登録パス）
   - 🎬 動画モード時: `~/Videos`
   - 📥 ローカル: `~/Downloads`
5. **🖼️ アートワーク/サムネイルの個別選択・おまかせダウンロード (`i` キー)**:
   - メディアに紐づく画像（高画質サムネイル、ジャケット画像など）を一覧表示し、好きな解像度・形式を選択して保存可能。
   - `a` キーで最高解像度（おまかせ）を瞬時にダウンロード保存（`cover.jpg` 等）。
   - アルバムダウンロード時に全曲で同じ画像を何度もDL・削除する無駄な挙動を完全に排除。
6. **💽 アルバム・プレイリスト対応 (NDJSON / JSON Lines 自動解析)**:
   - YouTube Music のアルバムやプレイリストを読み込むと、アルバム名、全トラック数、トラック一覧プレビューを詳細情報カラムに一覧表示。
7. **🏷️ MusicBrainz Picard 連携 (`p` キー)**:
   - `p` キー（または大文字 `P`）で Picard をバックグラウンド起動。貼り付け誤爆を防ぐため `p` は Picard 起動専用に分離。
   - 保存先フォルダ（外付けHDD Music 等）を引数として渡すため、即座に対象フォルダを開いてタグ編集・アルバム照会へ直結。
8. **📂 yazi ライクなディレクトリ操作 (`h`/`l`/`j`/`k`)**:
   - `d` キーで開くディレクトリブラウザでは、`j`/`k` の上下移動に加え、`h` で親ディレクトリへ移動、`l` で選択中の子ディレクトリへ移動可能。
9. **📋 クリップボード連携 ＆ 🔔 デスクトップ通知**:
   - 起動時は空の状態で安全に起動（自動読み取りなし）。`v` キーで必要な時だけクリップボードから URL を即時取得。
   - ダウンロード完了・エラー時はデスクトップ通知を発行。

## ⌨️ キーバインド一覧

### メイン画面
| キー | アクション |
| :--- | :--- |
| `v` | クリップボードから URL を貼り付け（メディア情報を取得開始） |
| `u` / `/` | URL を手動入力するモードへ切り替え |
| `Enter` | **ダウンロード開始**（メディア情報確認後に明示的に実行） |
| `Tab` | モード切替 (`Video` → `Audio` → `ThumbnailOnly`) |
| `r` | 動画の解像度上限切替 (`Unlimited` → `1080p` → `720p` → ...) |
| `a` | 音声フォーマット切替 (`MP3` → `FLAC` → `OPUS` → `M4A`) |
| `i` | **アートワーク / サムネイル選択モーダルを開く** |
| `F` / `f` | **`-F` ストリーム選択モーダルを開く**（特定ファイルだけ選択） |
| `d` | **保存先ディレクトリ選択 / 新規フォルダ作成モーダルを開く** |
| `p` / `P` | **MusicBrainz Picard を起動**（ダウンロード先フォルダを開く） |
| `q` | 終了 |

### 保存先ディレクトリブラウザ (`d` キー)
| キー | アクション |
| :--- | :--- |
| `j` / `Down` | 下へ移動 |
| `k` / `Up` | 上へ移動 |
| `h` / `Left` | **親ディレクトリへ戻る** (yaziライク) |
| `l` / `Right` / `Enter` | **選択中のフォルダを開く**（サブディレクトリへ入る） (yaziライク) |
| `Space` | **現在開いているフォルダを保存先として確定** |
| `n` / `+` | **新規フォルダを作成 (mkdir)**（名前を入力して Enter） |
| `1` 〜 `9` | 登録ルートディレクトリを即座に切り替え |
| `Esc` / `q` | 閉じる |

### アートワーク / サムネイル選択モーダル (`i` キー)
| キー | アクション |
| :--- | :--- |
| `j` / `Down`, `k` / `Up` | 画像候補を選択 |
| `Enter` | 選択中の画像をダウンロード保存（`cover.jpg` 等） |
| `a` | 最高画質（おまかせ）を自動保存 |
| `Esc` / `i` / `q` | 閉じる |

### `-F` フォーマット選択モーダル (`F` キー)
| キー | アクション |
| :--- | :--- |
| `j` / `Down`, `k` / `Up` | 下 / 上へ移動 |
| `Space` | 映像ストリーム（Video）の選択 / 解除 |
| `a` | 音声ストリーム（Audio）の選択 / 解除 |
| `c` | カスタムフォーマット選択のクリア（おまかせ自動選択に戻す） |
| `Enter` / `Esc` / `q` | 確定してモーダルを閉じる |

## ⚙️ 設定ファイル (`~/.config/shard/config.toml`)

初回起動時に自動生成されます：

```toml
[general]
default_mode = "video"
max_resolution = "unlimited"
auto_paste_clipboard = true
notify_on_complete = true

[audio]
format = "mp3"
quality = "0"
embed_thumbnail = true
add_metadata = true

# 登録ルートディレクトリ
[[bookmarks]]
id = 1
name = "Music"
path = "/path/to/Music"
category = "audio"

[[bookmarks]]
id = 2
name = "Videos"
path = "/path/to/Videos"
category = "video"

[[bookmarks]]
id = 3
name = "Downloads"
path = "/path/to/Downloads"
category = "any"
```

## 🚀 起動方法

```bash
git clone https://github.com/LilacAoi/shard.git
cd shard

# 1. ビルド＆実行
cargo run

# または Nix による直接実行
nix run .

# または nix build
nix build
./result/bin/shard
```
